# 정밀도 예산이 걸린 다항 반복 — 감도 인증서와 부분공간 오차 바닥

> *Precision-Budgeted Polynomial Iterations: Sensitivity Certificates and Subspace Error Floors* (2026-11-28)

📄 [`paper.pdf`](paper.pdf) · [`paper.tex`](paper.tex) · [`paper/`](paper/main.tex) · [`reproduce/`](reproduce/README.md) · 그림 3장 · 표 25개 · 25쪽

## 한 줄 요약

행렬을 극분해 인자로 보내는 다항 반복(뉴턴–슐츠와 미니맥스 변형, Muon이 쓰는 그것)이
$p$비트에서 내는 오차를 **감도 지표 $S_{\mathrm{pert}}(K)$와 부분공간 오차 바닥**으로
계산해, 4비트에서 틀린 세 가지 처방(안전 계수, 스텝 수, 정밀도 혼합)을 수치와 함께 바꾼다.

## 문제

Muon 계열 최적화기는 매 스텝 모멘텀 행렬의 극분해 인자 $UV^\top$를 고정된 5차 다항
반복 $X_t = p_t(X_{t-1})$, $p_t(x)=a_tx+b_tx^3+c_tx^5$ 로 계산합니다. 지금 쓰이는 계수와
안전 계수($\approx1.01$), 쿠션($0.02$), 첫 스텝 감쇠는 **정확 산술에서의 최적해**를 기준으로
정해진 처방이고, 주어진 정밀도에서 그것이 무엇을 얼마에 사는지는 따로 계산된 적이 없습니다.

## 기여

- **계산 가능한 감도 지표와 그 보정.** $S_{\mathrm{pert}}(K)$는 계수 궤도의 감도에 대한
  *접두 래칫*으로, 행렬도 반복도 필요 없는 $O(K)$ 스칼라입니다. 보정 상수 하나
  $c=0.142$ 로 $\mathrm{err}\approx E_K + c\,u\,S_{\mathrm{pert}}(K)$, $u=2^{-p}$ 라는 법칙을
  세우고 90개 셀에서 검증합니다(예측/측정 중앙 1.10, 범위 0.76–1.46). 마지막 스텝의
  감도만 쓰면(래칫이 아니라 말단값) 오차를 66배 과소평가합니다.
- **바닥은 부분공간 오차이고 불변입니다.** 정확 반복은 극분해 인자를 보존하므로 어떤
  스텝 수·설계·스케줄로도 바닥을 낮출 수 없습니다. 바닥은 스펙트럼이 아직 $[\ell,1]$을
  걸칠 때의 **첫 양자화**에서 생기고, 1차 공식이 정방 셀 54개 중 52개에서 10% 안에,
  직사각형이 요구하는 두 항 형태로는 Muon 루프의 500개 모멘텀 행렬 전부에서 0.6% 안에
  맞습니다. 따라서 바닥은 $\Theta(u/\ell)$이고, 앞서 보고된 지수 $\ell^{-0.73}$은 코드(chord)입니다.
- **상수가 닫힙니다.** 쌍 연산자 $[1/(\sigma_i+\sigma_j)]$를 $\sqrt d$ 로 정규화하면 가족·차원
  의존성이 한 수 $6.07$ 로 접힙니다. 이는 유도된 $2\sqrt2$ 와 프로파일 인자 $g$(180셀 중앙
  1.31, 범위 0.98–2.10)의 곱이고, $g$는 스펙트럼으로 만든 4블록 분산 프로파일 연산자의
  변(edge)이 맞춤 상수 없이 중앙 1.2%(97% 셀이 ±10% 안)로 재현합니다. $g$는 $d$가 아니라
  스펙트럼이 걸치는 십진 구간 수를 따릅니다.
- **예산 결정 두 가지.** 목표 정밀도 규칙 $K(\varepsilon)=\min\{K: E_K+c\,u\,S_{\mathrm{pert}}(K)\le\varepsilon\}$
  은 62개 셀에서 성립하고(측정/목표 0.02–1.15), 잘못된 동적 범위는 한 방향에서만 견딥니다
  (252개 결정). 등급 스케줄은 첫 슬롯 프리미엄이 2비트를 넘을 때 중앙 3.06배를 벌고
  실제 모멘텀에서는 중립(0.9비트)입니다.
- **fp8의 경계.** 유효숫자를 맞추면 fp8의 바닥은 무제한 지수 커널과 1–3% 안에서 같고,
  지수 창은 별개의 두 번째 제약으로 계산 가능한 경계를 가집니다. 온라인 예산 적응은
  **부정 결과**입니다. 스펙트럼을 쓰지 않는 센서 네 개는 평탄부를 보지 못합니다
  (80개 행렬 중 69개가 $K=5$, 나머지 $K=4$).

## 드러난 것

1. **안전 계수 $1.01\to\ge1.035$.** E5M2·$K=6$ 에서 $1.01$ 은 400스텝 안에 11시드런 중 6개를
   업데이트 오버플로로 잃고 $1.035$ 는 하나도 잃지 않습니다. 1,200스텝·25시드에서 한 번의
   Muon 호출 위험을 `digits` 에서 1/1,600 → 1/5,900, `diabetes` 에서 1/109 → 1/23,000 아래로
   낮추며, 대가는 업데이트 프로베니우스 노름의 0.4%입니다. 이는 여유이지 면역이 아닙니다.
   단일 반올림이 상태를 창 밖으로 밀면 5차항의 이득이 1을 넘고(변의 1.5배에서 2.2배, 2배에서
   9.3배) 업데이트가 $10^{44}$ 까지 달립니다. 상태를 창 안으로 클램프하면 50회 런 전부가
   끝나고, 학습률 10% 삭감은 11회 중 7회를 여전히 실패시킵니다.
2. **스텝 수 $K=6\to4$–$5$.** 여섯 번째 스텝은 창 오차의 1.5% 미만을 얻으려고 8비트를 씁니다.
   실제 모멘텀 80개 중 69개가 $K=5$, 나머지가 $K=4$ 를 원하고, 25비트에서 4스텝 E4M3
   업데이트는 $1.3\times10^{-1}$ 에 도달합니다.
3. **정밀도 혼합은 창 안에서만.** bf16 캐스트 + 2스텝 bf16 하이브리드는 $\sigma_{\max}$ 기준
   창, $\ell\le10^{-2}$ 안에서만 파레토 열등이 아닙니다. 40비트에서 이 하이브리드는
   $1.4\times10^{-1}$ 로 틀리는 반면 4스텝 bf16은 $2.4\times10^{-2}$ 이고, 실제 모멘텀 행렬
   전부에서 bf16보다 6배 나쁩니다.
4. **학습 손실은 평평하고, 낮은 정밀도가 깨는 것은 생존입니다.** 4개 포맷, 업데이트 오차
   0.73까지 손실은 $1.65\times$ 밖에 움직이지 않습니다. 실패는 학습 역학이 아니라 반복
   한 번 안에서 일어납니다(위 1항). 이 규모에서 "6%가 아니면 어디서인가"는 GPU 규모 실험이고,
   여기서 하지 않았습니다.

## 한계

커널은 모형이고 상수는 보정값입니다. 상태와 중간값을 $p$비트로 반올림하고 float64로
누적하며, FMA·누적 순서·광역 누산기의 서브노멀은 모형화하지 않습니다(대안 커널 셋에서 $c$가
최대 2.2배 움직입니다). 상수는 스펙트럼 가족에 따라 움직입니다(로그스페이스 0.43–0.97,
두 평탄부 가족에서 4–5배 낙관). 안전 계수는 창에서 잰 여유이지 수렴 손잡이가 아닙니다.
스텝 예산은 $128\times128$·$128\times64$ 모멘텀, $\ell_0=10^{-2}$ 한 창에서 측정했고
창이 넓어지면 평탄부가 움직입니다. 학습 측정은 5층·64차원, 조건당 11시드런(400스텝)과
25시드런(1,200스텝)에서 멈춥니다. 배분은 두 오퍼랜드와 슬롯별 스케줄을 따로 검증했지
함께 검증하지 않았고, 스케줄에는 온라인 형태가 없습니다.

## 빌드

`paper.tex` 는 그림 데이터 파일까지 스스로 담은 단일 파일입니다(`filecontents*`).

    tectonic -X compile paper.tex

TeX Live 로 빌드할 때는 그림 데이터를 쓸 디렉터리를 먼저 만들어 둡니다(파일 자체는
`filecontents*` 로 안에 들어 있습니다).

    mkdir -p figures/data && pdflatex paper.tex && pdflatex paper.tex

`paper/` 는 편집용 원본입니다. `main.tex` 가 `sections/*.tex` 를, 각 절이
`figures/*.tex`(pgfplots)를 읽고, 그림 좌표는 `figures/data/*.dat` 에 있습니다.

    cd paper && tectonic -X compile main.tex     # 또는 latexmk -pdf main.tex (bibtex 포함)

정적 검사 세 개는 TeX 없이 돕니다. 환경·중괄호 균형, `\ref`/`\label` 일치, 표 열 수,
금지 문구, 단어 수(`validate.py`), 그림과 데이터 표의 열 대조(`validate_figures.py`),
본문 쪽수 추정(`pagebudget.py`):

    cd paper && python3 validate.py && python3 validate_figures.py && python3 pagebudget.py

## 재현

모든 수치는 JSON 한 파일씩으로 남습니다. 스크립트가 그 JSON을 쓰고, 논문의 표는 그 JSON을
인용합니다.

    cd reproduce && ./run_all.sh

파이썬3 + `numpy`·`scipy`·`scikit-learn` 만 쓰고 GPU도 데이터 다운로드도 없습니다.
한 코어에서 전체 순서가 약 70분이며, `pilot25`(1,200스텝 × 25시드 × 3조건 × 2과제,
Muon 호출 약 450만 회)가 그 절반 이상입니다.

패키지 무결성은 `reproduce/` 안에서 확인합니다.

    cd reproduce && sha256sum -c MANIFEST.sha256 && sha256sum -c MANIFEST-paper.sha256

`reproduce/paper/` 는 `paper/` 와 바이트 단위로 같은 사본입니다. 패키지만 따로 풀어도
`MANIFEST-paper.sha256` 이 검증되도록(경로가 `paper/...`) 함께 두었습니다.
