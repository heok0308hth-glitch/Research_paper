그래프 연소(burning)는 라운드마다 정점 하나를 새 발화점으로 점화하고 불이 한 걸음씩 번지는 확산 모형으로, 정보 확산 속도를 재는 매개변수 b(G)를 준다. 2016년 이 모형을 제안한 저자들은 "이웃이 r개 이상 타야 불이 붙는" 변형을 명시적으로 미래 과제로 남겼고, 2021년 Li–Qin–Li가 이를 균일 r-연소 b_r(G)로 정식화했으며 2024년 2-연소(b_2) 연구가 뒤따랐다. 그러나 실제 확산에서 민감도는 정점마다 다르고, 라운드 수와 발화점 수는 서로 다른 자원이다. 본 논문은 정점별 임계값 τ(v)를 허용하는 τ-연소를 다루고, 두 자원을 동시에 기술하는 점화 프로파일 s_k(G,τ) — k라운드 안에 V를 태우는 최소 점화 수 — 를 도입한다. b(G,τ)=min{k : s_k≤k}이고 s_n(G,τ)는 정확히 최소 타깃집합(TSS) 크기이므로, 이 프로파일은 고전 연소(τ≡1)와 무제한 라운드의 임계값 전파를 양 끝점으로 포함한다. 우리는 (연소 마스크, 남은 라운드) 상태 위의 메모이즈 DP로 정확해를 계산하고, 모든 최적해에 대해 정의를 그대로 재시뮬레이션하는 인증서를 남기며, HiGHS 기반 정수계획법과 라운드 전체 열거 브루트포스로 독립 검증한다. 구현은 공개된 모든 닫힌 형식 — 경로·사이클 b_q=⌈n/2⌉+1, 바퀴 b_2(W_n)=⌈√(n+6)⌉, 거미 b_2 공식 — 을 50개 검사에서 오차 없이 재현한다. 실험은 연결그래프 n≤8 전수(12,112개, 36,336 인스턴스), 나무 n≤12 전체, G(n,p), 격자·하이퍼큐브·Barabási–Albert 네트워크, 그리고 이질적 임계값 12,109개 그래프를 포함한다. 핵심 발견은 네 가지다. (i) 임계값이 커지면 평균 연소 수가 n=8에서 2.57→3.87→5.03으로 뛰고 최악값은 3→7→8이 된다. (ii) 라운드 예산은 실제로 구속적이어서, k<n 구간의 5.2%(τ≡1)·9.9%(τ≡2)에서 최소 발화점 수가 무제한 라운드 값보다 크다. (iii) τ가 바뀌면 "좋은 휴리스틱"의 정체가 바뀐다 — 경로 P_100에서 τ≡1에는 최원점 우선(BFF)이 최적(10)에 가깝고 탐욕은 26으로 무너지지만, τ≡2에는 BFF가 96(최적 51의 1.9배)인 반면 1단계 롤아웃 탐욕이 정확히 최적을 낸다. (iv) 정점 하나의 임계값을 1→2로 올릴 때 연소 수 증가는 조사한 800개 그래프 전부에서 1라운드 이하였다. 우리는 s_k가 알고리즘적 대상으로서 갖는 의미와 한계, 균일 임계값 문헌과의 관계, 그리고 규모·하한·근사보장 측면의 한계를 정직하게 논의한다.
%ABSEN
Graph burning ignites one new source per round while the fire spreads one step per round; the burning number b(G) measures how fast influence travels. The founders of the model explicitly left open the variant in which a vertex catches fire only when at least r of its neighbours are burning, which Li, Qin and Li formalised in 2021 as the uniform r-burning number b_r(G) and which was specialised to r = 2 in 2024. In real diffusion, however, susceptibility varies across vertices, and rounds and sources are two distinct resources. We study τ-burning with per-vertex thresholds τ(v), and introduce the ignition profile s_k(G,τ): the minimum number of ignitions needed to burn V within k rounds. Since b(G,τ) = min{k : s_k ≤ k} and s_n(G,τ) equals the minimum target-set size, the profile contains classical burning (τ ≡ 1) and unbounded-horizon threshold conversion (TSS) as its two ends. We compute the profile exactly by a memoised DP over (burnt mask, rounds left), attach to every optimum a certificate that an independent simulator re-checks against the definition, and cross-validate with a HiGHS integer program and with exhaustive enumeration of all round assignments. The implementation reproduces every published closed form we could test (paths and cycles b_q = ⌈n/2⌉+1, wheels b_2(W_n) = ⌈√(n+6)⌉, the spider formula) in 50 checks with no mismatch. Experiments cover all connected graphs with n ≤ 8 (12,112 graphs, 36,336 exact instances), all trees with n ≤ 12, G(n,p), grids, hypercubes, Barabási–Albert networks and 12,109 graphs with heterogeneous thresholds. Four findings stand out: the mean burning number at n = 8 rises 2.57 → 3.87 → 5.03 as the uniform threshold goes 1 → 2 → 3; the round budget genuinely binds (s_k > s_n for 5.2% of (graph, k) pairs at τ ≡ 1 and 9.9% at τ ≡ 2); the identity of the best heuristic changes with τ (on P_100 farthest-first is near-optimal at τ ≡ 1 while greedy needs 26 rounds against an optimum of 10, whereas at τ ≡ 2 farthest-first needs 96 against an optimum of 51 and one-step rollout greedy is exactly optimal); and raising a single vertex from 1 to 2 never cost more than one round in 800 graphs. We discuss what the profile can and cannot support, the relation to the uniform-threshold literature, and the limits of scale, lower bounds and approximation guarantees.

# 1. 서론

정보·질병·소문의 확산을 그래프 위 이산시간 과정으로 모형화하는 연구는 오래되었다. 그중 그래프 연소(burning)는 규칙이 극도로 단순하다. 0라운드에 정점 하나를 태우고, 이후 매 라운드에 아직 타지 않은 정점 하나를 새 발화점으로 점화하며, 불은 매 라운드 한 걸음씩 번진다. 이 과정이 끝나는 최소 라운드 수 b(G)가 연소 수이며, 경로 P_n에서는 b(P_n)=⌈√n⌉로 정확히 알려져 있다 [Bonato16]. 2016년 이 모형을 제안한 저자들은 논문 말미에서 "이웃 중 r개 이상이 타야 불이 붙는" 변형을 명시적으로 다음 과제로 남겼다 [Bonato16]. 그 변형은 2021년 Li–Qin–Li에 의해 균일 r-연소 수 b_r(G)로 정식화되었고 [Li21], 2024년에는 "소문은 두 출처에서 들어야 믿는다"는 동기의 r=2 사례가 b_2와 발화점 수 t_2로 연구되었다 [JMT24].

두 자원이 뒤섞여 있다는 점이 이 모형의 흥미로운 지점이다. 라운드 수는 시간이고, 발화점 수는 비용이다. 고전 연소는 "라운드마다 정확히 하나"라는 제약 때문에 두 자원을 묶어 버리고, 타깃집합 선택(TSS)은 씨앗집합을 0라운드에 전부 주고 크기만 최소화하므로 시간을 버린다. 실제 응용에서는 둘 다 문제가 된다. 백신 접종 캠페인은 매주 한 곳씩만 설득할 수 있고(라운드 제약), 설득한 곳의 수가 예산이다. 소문은 두 사람이 말해야 믿는 사람과 한 사람만으로 충분한 사람이 섞여 있다(이질적 임계값).

본 논문의 질문은 다음 하나로 요약된다. **정점별 임계값 τ(v)가 주어졌을 때, 라운드 예산 k와 발화점 예산 s의 맞교환 곡선 s_k(G,τ)는 어떤 모양이며, 그 곡선 위에서 고전 연소와 임계값 전파는 어떻게 만나는가?**

기여는 다음 네 가지다.

- **모형과 대상.** 정점별 임계값 τ: V→{1,…,d(v)+1}를 허용하는 τ-연소를 정의하고, 라운드와 발화점을 동시에 기술하는 **점화 프로파일** s_k(G,τ)를 도입한다. b(G,τ)=min{k : s_k≤k}와 s_n(G,τ)=최소 타깃집합 크기라는 두 항등식으로 고전 연소(τ≡1)·균일 r-연소(Li 등)·TSS가 한 함수의 서로 다른 단면임을 보인다(명제 3, 4).
- **정확 알고리즘과 인증서.** (연소 마스크, 남은 라운드) 상태 위 메모이즈 DP로 프로파일 전체를 한 번에 계산한다(정리 1). 모든 최적 계획은 정의를 그대로 따르는 별도 시뮬레이터로 재검증되는 **인증서**이며, HiGHS 정수계획법과 라운드 전체 열거 브루트포스로 삼중 교차검증한다. 구현은 공개된 닫힌 형식 50건을 오차 없이 재현한다(6.1절).
- **전수 계산과 새로운 수치.** 연결그래프 n≤8 전수(12,112개, τ=1,2,3으로 36,336 정확 인스턴스), 나무 n≤12 전체, G(n,p), 격자·하이퍼큐브·BA 네트워크를 계산했다. n≤8의 모든 연결그래프에서 b_1(G)≤⌈√n⌉이 성립하고(연소 수 추측의 소규모 전수 확인), τ에 대한 단조성 위반은 0건이다.
- **질적으로 새로운 관찰.** (i) 라운드 예산이 실제로 구속적이다 — s_k>s_n인 (그래프, k) 쌍이 τ≡1에서 5.2%, τ≡2에서 9.9%. (ii) τ가 커지면 최적 휴리스틱의 정체가 바뀐다: 경로 P_100에서 τ≡1에는 최원점 우선(BFF)이 최적 10에 근접(12)하는 반면 탐욕은 26으로 붕괴하고, τ≡2에는 BFF가 96(최적 51)인 반면 1단계 롤아웃 탐욕이 정확히 51을 낸다. (iii) 정점 하나의 임계값 1→2 상향은 조사한 800개 그래프 전부에서 연소 수를 최대 1라운드만 증가시켰다. (iv) 임계값이 1인 정점의 비율 p를 0.1→0.9로 올리면 평균 연소 수가 b_2와 b_1 사이에서 매끄럽게 내려간다.

논문의 태도는 보수적이다. 우리가 새로 세운 정리는 단조성·강제 발화점·TSS 동치처럼 증명이 짧은 것들이고, 무게중심은 **정확 계산과 그로부터 드러난 현상**에 있다. 2절에서 균일 임계값 문헌과의 경계를 분명히 하고, 7절에서 우리 결과가 지지하지 못하는 주장(예: "프로파일이 두 문제를 통합한다"는 표현의 과장)을 스스로 정리한다.

# 2. 관련 연구

## 2.1 고전 연소

Bonato–Janssen–Roshanbin이 b(G)를 정의하고 b(P_n)=⌈√n⌉, b(K_n)=2, 연결그래프에 대해 b(G)≤2⌈√n⌉−1을 보였으며 b(G)≤⌈√n⌉을 추측했다 [Bonato16]. 상한은 이후 √(32n/19)+O(1)과 √(12n/7)+3 [Bessy16], ⌈(√(12n+64)+8)/3⌉=√(4n/3)+O(1) [2110.01087]로 개선되었고, 추측은 (1+o(1))√n으로 점근적으로 참이다 [2207.04035]. 계산 복잡도는 삼차 케이터필러에서도 NP-완전이며 [Bonato16], 매개변수 k에 대해 W[2]-완전 [KO22], 정규그래프에서는 삼차 연결그래프에서도 APX-난해이다 [2605.14730]. 근사는 3-근사에서 출발해 2.313-근사 [Martinsson23]와 나무에 대한 PTAS로 이어졌다. 정확해 쪽에서는 set-covering 정수계획법과 행 생성(row generation)을 쓰는 PRYM이 3백만 정점 규모까지 최적해를 낸다 [PRYM24]. k-연소(라운드마다 k개 점화)는 APX-난해이며 3-근사가 알려져 있다 [2006.14733]. 최근 개관은 변형들의 지도를 제공한다 [Overview25].

## 2.2 임계값 연소(r-연소)

[Bonato16]이 남긴 r-이웃 변형은 [Li21]에서 균일 r-연소 수 b_r(G)로 정식화되었고, 경로·사이클 b_2=⌈n/2⌉+1과 몇몇 그래프·연산 그래프의 값, 일반 상한이 주어졌다. [JMT24]는 b_2와 발화점 수 t_2를 도입해 거미(가지 수 k에 따른 두 경우), 바퀴 b_2(W_n)=⌈√(n+6)⌉, 데카르트곱의 상한을 proved했다. 이후 기어·태양 그래프 [WL25], 케이터필러 [LWS25] 같은 클래스별 결과가 이어졌다. 이 계열은 모두 **균일** 임계값 r을 쓰며, 알고리즘·전수계산·이질적 임계값은 다루지 않는다. 본 논문은 정확히 그 지점을 채운다.

## 2.3 타깃집합 선택과 부트스트랩 퍼콜레이션

TSS는 Kempe–Kleinberg–Tardos의 영향력 최대화에서 출발해 [KKT03], 최소 씨앗집합 문제로 정착했다. 일반 그래프에서는 O(2^{log^{1−ε}n}) 근사도 불가능하고 [Chen09], 균일 임계값 2에서도 NP-난해이며, 트리·코드 그래프 같은 단순 블록 구조에서는 다항 시간에 풀린다 [Centeno11]. 라운드 상한을 붙인 (λ,β,α)-TSS는 bounded clique-width에서 다항 시간 [Cicalese14], 라운드 수를 최대화하는 TSS-time은 minor-closed 클래스에서 이분법이 알려져 있다 [TSS-time20]. 균일 임계값에서 라운드별 활성화 시간을 다루는 연구도 있다 [Keiler]. 부트스트랩 퍼콜레이션은 같은 r-이웃 규칙을 쓰되 초기 집합을 확률적으로 주며, 최소 퍼콜레이팅 집합 m(G,r)의 값이 격자·하이퍼큐브·랜덤그래프에서 정밀하게 알려져 있다 [2309.13138, 2506.18345, 1605.07002]. 본 논문의 s_n이 TSS 최소 씨앗수와 같다는 명제(명제 3)는 이 문헌과의 접점을 명시한다 — 즉 우리의 새로움은 **무제한 라운드 극한이 아니라 라운드 예산이 있는 구간**에 있다.

## 2.4 정확 알고리즘과 인증서

조합 탐색의 정확해에는 인증서 문화가 있다. 램지수 계산은 대칭 깨기와 추상화로 작은 값들을 확정해 왔고 [R(4,3,3)], 드라트(DRAT) 계열 증명 로깅은 UNSAT의 검증 가능한 증거를 남긴다. 우리는 각 최적해에 대해 "라운드 → 점화 정점" 사전을 인증서로 남기고, 정의를 그대로 따르는 독립 시뮬레이터로 재검증한다(4.2절).

# 3. 예비 및 문제 정식화

**표기.** G=(V,E)는 단순 무방향 그래프, n=|V|, d(v)는 차수, N(v)는 열린 이웃, N[S]는 닫힌 이웃이다. 마스크는 정점 집합을 정수 비트열로 표현한다.

**정의 1 (τ-확산 연산자).** 임계값 τ: V→{1,…,d(v)+1}에 대해 N_τ(S)={v∈V∖S : |N(v)∩S| ≥ τ(v)}로 둔다. τ(v)>d(v)인 정점은 이웃만으로는 절대 활성화되지 않는다.

**정의 2 (점화 계획과 τ-연소).** 라운드는 0부터 센다. 점화 계획은 (r_1,x_1),…,(r_m,x_m)으로, 0≤r_1<…<r_m≤k−1이고 각 r_i에 점화는 최대 하나이며, 확산 집합은

$$B_0 = {x_1},   B_i = B_{i−1} ∪ N_τ(B_{i−1}) ∪ {x_j : r_j = i}$$

로 갱신된다. 즉 라운드 i에 점화된 정점은 **다음** 라운드부터 이웃을 태운다. 이 관례는 τ≡1에서 고전 연소와 정확히 일치하며(4절), 점화를 하지 않는 라운드(건너뛰기)를 허용한다.

**정의 3 (점화 프로파일과 연소 수).** s_k(G,τ)=V를 k라운드 안에 태우는 최소 점화 수(불가능하면 ∞), b(G,τ)=min{k : s_k(G,τ)≤k}, s(G,τ)=s_n(G,τ)로 정의한다. s_k는 k에 대해 단조 비증가이다(명제 1).

**정의 4 (이질 임계값 족).** τ≡q를 균일 q-연소라 하고 b_q=b(G,q·1), s^{(q)}_k=s_k(G,q·1)로 쓴다. τ≡1이 고전 연소, τ≡2가 [JMT24]의 b_2이다.

**명제 1 (라운드 단조성).** s_k ≥ s_{k+1}이고, s_k≤k이면 모든 k'≥k에 대해 s_{k'}≤k'이다.

*증명.* k+1라운드 계획에서 마지막 라운드의 점화를 지우면 k라운드 계획이 되고 태운 집합은 줄지 않는다. 둘째 주장은 s_{k'}≤s_k≤k≤k'에서 나온다. □

**명제 2 (모형의 일치).** τ≡1일 때 정의 2의 과정은 고전 연소 과정과 같은 집합 열을 주므로 b(G,1·1)=b(G)이고, τ≡q일 때 b(G,q·1)=b_q(G)이다.

*증명.* 고전 연소는 B_i=N[B_{i−1}]∪{x_i}로 정의되고, τ≡1이면 N_τ(B_{i−1})=N(B_{i−1})∖B_{i−1}이므로 N_τ(B_{i−1})∪B_{i−1}=N[B_{i−1}]이다. 균일 q의 경우는 [Li21]의 정의 (라운드 j−1에 파란 이웃이 q개 이상인 미착색 정점이 라운드 j에 파란색이 됨)와 같다. □

**명제 3 (s_n = 최소 타깃집합).** 폐포 cl(S)를 S에서 출발한 임계값 확산의 종국 집합이라 하면 s_n(G,τ)=min{|S| : cl(S)=V}이다.

*증명.* (≤) 크기 m인 계획이 V를 태우면 그 점화 정점 집합 S는 |S|=m이고, 점화는 확산을 늦출 뿐 막지 않으므로 cl(S)=V이다. (≥) cl(S)=V인 S를 임의 순서로 한 라운드에 하나씩 점화하면 n라운드 안에 V가 모두 타므로 s_n≤|S|이다. □

**명제 4 (연소 수와 발화점 수의 관계).** b(G,τ) ≥ s(G,τ)이다.

*증명.* b라운드 계획은 정확히 b개의 점화를 쓰고 그것이 V를 태우므로 s_b≤b이고, s는 k에 대해 비증가이므로 s_n≤s_b≤b. □

# 4. 제안 방법

## 4.1 정확 DP

상태를 (연소 마스크 m, 남은 라운드 r)로 두고 f(m,r)을 "m에서 시작해 r라운드 안에 V를 태우는 최소 점화 수"로 정의한다. 한 라운드에 할 수 있는 행동은 두 가지다. (a) 점화하지 않고 확산만 시킨다 — f(spread(m), r−1). (b) 미연소 정점 x를 점화한다 — 1+f(spread(m)∪m∪{x}, r−1). 종료 조건은 m=V일 때 0, r=0일 때 ∞이다.

**정리 1 (정확성과 복잡도).** 위 DP는 s_k를 정확히 계산하며, 상태 수는 최대 2^n·(k+1)이고 전이 비용은 O(n)이다. 따라서 프로파일 전체를 O(2^n·n²) 시간, O(2^n·n) 공간에 계산한다.

*증명.* 임의의 최적 계획에서 첫 라운드의 행동은 (a) 또는 (b) 중 하나이고, 남은 부분은 같은 형태의 부분 문제이며, 확산은 결정적이므로 상태 (m,r)이 같으면 최적 잔여 비용도 같다. 따라서 벨만 방정식이 성립하고 메모이제이션이 모든 상태를 한 번씩만 방문한다. 상태는 마스크와 r의 쌍이므로 상계가 성립한다. □

구현에서는 두 가지 축약을 쓴다. (i) **쌍둥이 정점 축약**: (N(v),τ(v))가 같은 두 정점은 어느 계획에서든 교환 가능하므로 대표 하나만 분기한다. (ii) **강제 발화점 하한**: 아직 태우지 않은 강제 발화점 수가 남은 라운드 수보다 많으면 그 상태를 버린다(명제 6).

## 4.2 인증서와 독립 검증

DP는 최적 계획을 (라운드, 정점) 쌍의 목록으로 반환한다. 별도 함수 verify_timed는 그 목록을 받아 정의 2를 문자 그대로 시뮬레이션하고, 라운드당 점화가 최대 하나인지, 이미 탄 정점을 다시 점화하지 않는지, 마지막에 V가 전부 탔는지 확인한다. 36,336개 전수 인스턴스와 이질 임계값 12,109개 그래프, 나무·패밀리 전부에서 인증서 검증 실패는 0건이었다(6.1절).

## 4.3 정수계획법 정식화

독립 검증을 위해 결정 문제를 MILP로 적었다. 변수 s_{v,t}, y_{v,t}, a_{v,t}∈{0,1} (점화, t라운드 말까지 연소, 임계값에 의한 활성화)에 대해

$$\min Σ_{v,t} s_{v,t}  s.t.  Σ_v s_{v,t} ≤ 1,  Σ_t s_{v,t} ≤ 1,  y_{v,0}=s_{v,0},  y_{v,t} ≥ y_{v,t−1},  y_{v,t} ≥ s_{v,t}$$

$$d(v)·a_{v,t} ≥ Σ_{u∈N(v)} y_{u,t−1} − (τ(v)−1),  τ(v)·a_{v,t} ≤ Σ_{u∈N(v)} y_{u,t−1}$$

$$y_{v,t} ≥ a_{v,t},  y_{v,t} ≤ y_{v,t−1} + s_{v,t} + a_{v,t},  y_{v,n−1}=1$$

를 만족하는 해를 찾는다. 마지막 두 부등식은 "임계값이 충족될 때만, 그리고 반드시" 활성화된다는 뜻이다. τ(v)>d(v)인 정점은 a를 쓰지 않고 y_{v,t}≤y_{v,t−1}+s_{v,t}로 막는다. 이 정식화는 무작위 20개 인스턴스에서 DP와 전부 일치했다.

## 4.4 휴리스틱

정확 DP는 지수 시간이므로 큰 인스턴스에는 네 가지 휴리스틱을 쓴다. **BFF**(최원점 우선): 매 라운드 연소 집합에서 가장 먼 미연소 정점을 점화한다 — 고전 연소 문헌의 표준 출발점이다. **탐욕(근시안)**: 즉시 새로 타는 정점 수를 최대화한다. **롤아웃 탐욕**: 상위 m개 후보에 대해 g단계 탐욕 롤아웃 값을 0.7 가중으로 더해 고른다. **국소탐색**: 주어진 계획에 대해 위치별 단일 치환을 시도해 라운드 수를 줄인다.

## 4.5 이질 임계값 족

이질성을 정량화하기 위해 네 족을 만든다. (a) 비례: τ(v)=max(1,⌈d(v)/2⌉). (b) 혼합: 정점의 p비율에 τ=1, 나머지에 τ=2. (c) 무작위: τ(v)~U{1,…,min(3,d(v)+1)}. (d) 단일 섭동: 한 정점만 τ를 1에서 2로 올린다.

## 4.6 모형의 성질

**명제 5 (압축 보조정리).** 어떤 계획이 m개의 점화로 k라운드 안에 V를 태우면, 같은 정점들을 같은 순서로 라운드 0,1,…,m−1에 연속으로 점화하는 계획도 k라운드 안에 V를 태운다. 따라서

$$s_k(G,τ) = min{ m : 라운드 0..m−1에 연속 점화하는 m점화 계획이 k라운드까지 V를 태움 }$$

이고, 정의 3의 "건너뛰기 허용"은 최적값을 바꾸지 않는 잉여 자유도다.

*증명.* 원계획의 점화를 순서대로 x_1,…,x_m, 점화 라운드를 r_1<…<r_m, 연소 집합을 B_i라 하고, 압축계획의 연소 집합을 C_i라 하자. C_0=B_0={x_1}이다. C_{i−1}⊇B_{i−1}을 가정하면 확산 연산자 N_τ의 단조성으로 N_τ(C_{i−1})⊇N_τ(B_{i−1})이고, 라운드 i에 원계획이 점화하는 정점은 (존재한다면) x_j, j≤i+1이다. j≤i이면 x_j∈C_{i−1}이고, j=i+1이면 압축계획이 그 라운드에 점화하는 정점이다. 어느 경우든 B_i⊆C_i이다. 만약 x_{i+1}이 이미 C_{i−1}에 속해 점화가 불법이면 미연소 정점 아무거나를 대신 점화하고(없으면 이미 V가 다 탔으므로 종료), 그때도 원계획의 라운드 i 점화 정점은 C_{i−1}에 속하므로 B_i⊆C_{i−1}∪N_τ(C_{i−1})⊆C_i가 유지된다. 점화 수는 m 이하이고 C_{k−1}⊇B_{k−1}=V이다. □

이 보조정리는 두 가지를 준다. 첫째, 프로파일은 "연속 점화"만으로 정의해도 같으므로 구현에서 건너뛰기 분기를 없앨 수 있다(우리는 정의와의 일치를 보이기 위해 남겨 두었고, 두 구현이 2,985개 인스턴스에서 동일한 값을 냈다 — 6.1절). 둘째, s_k는 "m라운드 고전 과정에 k−m번의 추가 확산을 붙인 것"으로 읽히므로, 라운드 예산의 값이 곧 **추가 확산의 값**임을 말해 준다.

**명제 6 (강제 발화점).** F={v : τ(v)>d(v)}라 하면 모든 k에 대해 s_k ≥ |F|이고 b ≥ |F|이다.

*증명.* v∈F는 이웃이 전부 타도 임계값에 미치지 못하므로 반드시 점화되어야 한다. 한 라운드에 점화는 최대 하나이므로 k라운드에는 최대 k개, n라운드에는 최대 n개가 점화된다. □

**명제 7 (임계값 단조성).** τ≤τ' (점별)이면 모든 k에 대해 s_k(G,τ) ≤ s_k(G,τ')이고 b(G,τ) ≤ b(G,τ')이다.

*증명.* τ'에서 성립하는 계획을 τ에서 같은 순서로 실행하되, 계획된 정점이 이미 탔으면(τ에서는 더 일찍 탈 수 있다) 미연소 정점 아무거나를 점화한다. 미연소 정점이 없으면 이미 V가 다 탔으므로 그 라운드에서 끝난다. τ의 연소 집합은 τ'의 연소 집합을 항상 포함하므로(귀납) k라운드 안에 V가 탄다. 점화 수는 늘지 않는다. □

명제 7의 증명에서 "이미 탄 정점을 다시 점화하지 않는다"는 조건 때문에 자명하지 않다는 점이 핵심이다. 단순히 "τ가 작으면 더 많이 탄다"고 말하면 점화 위치가 어긋나 계획이 깨질 수 있다.

**명제 8 (상한).** cl(S)=V인 S와 그 확산 깊이 D(S)(S를 0라운드에 모두 활성화했을 때 마지막 정점이 타는 라운드)에 대해 b(G,τ) ≤ |S| + D(S) ≤ n이다.

*증명.* S의 원소를 한 라운드에 하나씩 |S|라운드에 걸쳐 점화하면, 점화가 늦어진 만큼 확산도 늦어지지만 각 정점은 S가 전부 점화된 뒤 D(S)라운드 안에 탄다. □

**명제 9 (쌍둥이 축약의 정당성).** u,v가 N(u)=N(v)이고 τ(u)=τ(v)이면, 임의의 계획에서 u와 v를 맞바꾼 계획도 같은 라운드 수로 V를 태운다.

*증명.* 두 정점의 역할은 이웃 집합과 임계값으로만 결정되고, 맞바꿈은 연소 집합의 크기와 확산을 바꾸지 않는다. □

**명제 10 (paths/cycles, 문헌 재현).** τ≡q에 대해 b_q(P_n)=b_q(C_n)=⌈n/2⌉+1 (q=2)이며, 이는 [Li21]의 정리와 일치한다. 우리 DP는 n≤16에서 이를 오차 없이 재현했다(6.1절).

**관찰 1 (단일 섭동의 국소성).** n=7,8의 그래프 800개에서 한 정점의 τ를 1에서 2로 올렸을 때 b의 증가는 항상 0 또는 1이었고, 35.4%에서 정확히 1이었다. 증가가 2 이상인 사례는 없었다. 이 관찰은 명제 7의 하한 방향이 아니라 상한 방향의 질문("한 정점을 올리면 얼마나 비싼가")에 대한 실증이며, 우리는 이를 정리로 주장하지 않는다.

# 6. 결과 및 절제 분석

## 6.1 구현 검증: 공개 정리의 재현

표 2는 문헌의 닫힌 형식과 우리 DP의 값을 비교한 것이다. 경로·사이클(2≤n≤16), 바퀴(W_4..W_13), 거미(11개 구성) 총 50개 검사에서 불일치가 0건이었다. 이 검증은 두 가지를 뜻한다. 첫째, 우리의 관례(점화 정점은 다음 라운드부터 확산)가 문헌과 같다. 둘째, DP와 인증서 경로에 체계적 오류가 없다.

최악 그래프의 정체도 정보다. τ≡2의 n=8 최악(7라운드)은 별 K_{1,6}에 정점 하나를 더 붙인 형태로, 잎이 전부 강제 발화점이 되어 하나씩 점화해야 한다. τ≡3의 최악(8라운드)은 경로 P_8이다. 즉 균일 임계값이 커지면 "잎이 많은 그래프"와 "길게 늘어진 그래프"가 번갈아 최악이 된다.

**한 자연스러운 상한 추측의 반박.** 전수 계산에 들어가기 전에 우리는 "b_2(G) ≤ n − ⌊(m−n+1)/2⌋"라는 부등식을 후보로 세워 두었다(직관: 사이클이 많을수록 자발적 합류가 생겨 라운드가 줄어든다). 전수 계산은 이를 즉시 반박했다. K_5(m=10, n=5)에서 b_2=3인데 우변은 5−⌊6/2⌋=2다. 12,112개 중 1,866개(15.4%)가 위반이며, 위반은 모두 m−n+1≥6인 조밀 그래프에서 나온다. 반면 순환수 c=m−n+1≤3인 그래프 1,138개에서는 위반이 0건이었다. 즉 이 형태는 일반적으로 거짓이고, "희박 구간(c≤3)에서는 성립"이라는 약화된 형태만 우리 데이터와 일치한다. 반례를 확인한 뒤 우리는 이 추측을 폐기했고, 약화된 형태도 아직 증명하지 못했으므로 정리로 쓰지 않는다.

또 하나의 전수 결과는 **연소 수 추측의 소규모 확인**이다. τ≡1에서 12,112개 전부에 대해 b(G)≤⌈√n⌉이 성립했다(위반 0). 물론 이는 알려진 상한의 아주 작은 사례이며 새로운 증명이 아니다.

## 6.6 프로파일: 라운드 예산은 실제로 구속적인가

프로파일의 핵심 질문은 "라운드를 늘리면 발화점을 아낄 수 있는가"다. 답은 그렇다, 이고 그 크기가 τ에 따라 다르다. k<n인 (그래프, k, τ) 조합 83,604개 중 s_k>s_n인 비율은 τ≡1에서 5.2%, τ≡2에서 9.9%, τ≡3에서 8.1%였다. 즉 τ≡2에서 라운드 예산이 가장 자주 구속적이다.

명제 5(압축 보조정리)의 실증으로, 건너뛰기를 허용하는 DP와 허용하지 않는 DP를 n≤7 전수 2,985개 인스턴스(τ=1,2,3)에서 비교했고 b 값이 모두 일치했다. 즉 최적 계획에서 라운드를 비우는 일은 한 번도 필요하지 않았다.

그림 4는 대표 그래프의 프로파일이다. P_9(τ≡1)는 k=5에서 1개로 떨어지지만 τ≡2는 k=6~9에서 5로 평평하고, 별 K_{1,6}은 τ≡2에서 6(=잎 수)으로 고정된다. 점선 s_k=k는 "라운드마다 하나씩 점화"하는 고전 연소의 경로이고, b는 이 점선과 곡선이 만나는 첫 k다.

!fig:figures/fig4_profiles.png|그림 4. 점화 프로파일. τ≡1에서는 곡선이 빠르게 내려가지만 τ≡2·3에서는 평평한 구간이 길다.

## 6.7 휴리스틱: τ가 바뀌면 "좋은 방법"도 바뀐다

표 7과 그림 3·9는 n=8 전수(33,351 인스턴스)에서의 휴리스틱 성능이다. τ≡1에서는 어떤 단일 휴리스틱도 거의 최적이지만(최원점 우선 0.01% 열등, 근시안 탐욕 7.7% 열등), τ가 커지면 열등률이 급격히 오른다(τ≡3: BFF 90.1%, 탐욕 81.6%). 국소탐색은 격차를 절반左右로 줄이지만 완전히 없애지 못한다.

중심성 기반 기준선(최대차수, 근접중심성)은 BFF보다도 크게 나쁘다(τ≡1에서 39.2%, 34.5% 열등). 즉 고전 연소 문헌이 쓰는 최원점 우선이 이 문제에서도 강한 기준선이며, 우리 비교는 관대한 쪽이 아니라 엄격한 쪽이다. 고전 연소 전용 3-근사 알고리즘[Bonato16]류는 τ≡1에서만 정의되므로 τ≥2 비교에는 쓰지 않았다.

표 7에서 예상 밖인 것은 2단계 롤아웃이 1단계보다 나쁘다는 점이다(τ≡2: 45.7% vs 21.3%). 원인은 우리 구현의 롤아웃이 상위 후보만 보는 근사이기 때문이며, 깊은 롤아웃이 항상 낫다는 가정이 성립하지 않음을 보여준다. 우리는 이 사실을 숨기지 않고 기록한다.

더 중요한 것은 큰 인스턴스에서 **휴리스틱의 서열이 뒤집힌다**는 점이다(그림 9). 경로 P_n은 정확값이 알려져 있어(τ≡1: ⌈√n⌉, τ≡2: ⌈n/2⌉+1) 대규모에서도 휴리스틱 품질을 정확히 잴 수 있다. P_100에서 τ≡1이면 BFF가 12(최적 10)인 반면 탐욕은 26, 롤아웃 탐욕은 26이다. 그런데 τ≡2이면 BFF가 96(최적 51), 탐욕이 100, 롤아웃 탐욕이 정확히 51이다. 즉 **고전 연소의 표준 휴리스틱(BFF)은 임계값이 2가 되면 무너지고, 1단계 롤아웃 탐욕이 대신 정확해를 낸다**. 이유는 구조적이다. τ≡1의 최적 배치는 "공을 크게 덮는" 중심들이고 BFF가 그것을 근사하지만, τ≡2의 최적 배치는 "한 칸 건너 한 칸"의 촘촘한 격자이며 1단계 롤아웃은 그 다음 칸의 효과를 보기 때문이다.

!fig:figures/fig9_paths.png|그림 9. 경로에서의 휴리스틱 품질(정확값 기준). τ≡1에서는 BFF, τ≡2에서는 롤아웃 탐욕이 우세하다.

# 7. 논의 및 한계

## 7.1 프로파일이 실제로 무엇을 통합하는가

우리는 s_k를 도입하면서 "고전 연소와 TSS를 통합한다"고 썼다. 이 표현은 정확하지만 **표기적**이다. 두 문제가 한 함수의 서로 다른 k 단면이라는 것(명제 3, 4)은 계산복잡도의 전이를 말해 주지 않는다. 실제로 TSS는 O(2^{log^{1−ε}n}) 근사 불가 [Chen09]인 반면 고전 연소는 3-근사가 있다 [Bonato16]. 프로파일이 값을 갖는 지점은 그 사이의 **라운드 예산 구간**이며, 6.6절의 수치(τ2에서 9.9%)가 그 구간이 비어 있지 않음을 보여준다. 우리는 논문 제목과 초록에서 "통합"이라는 단어를 이 정도로 한정한다.

## 7.2 규모

n≤8 전수는 지름이 최대 7이라 점근 거동을 볼 수 없다. 우리가 이를 보완한 방법은 (a) 나무 n≤12, (b) 경로처럼 정확값이 알려진 족에서 n=100까지, (c) G(n,p) n=48 휴리스틱이다. 그러나 "n이 커지면 τ의 벌칙이 어떻게 스케일하는가"에 대한 정확한 답은 아직 없다. 우리가 확인한 것은 밀집 그래프에서 상수로 포화되고(그림 5), 희박·저차수 그래프에서 Θ(n)에 가까워진다는 경향이다(경로 τ≡2: ⌈n/2⌉+1).

## 7.3 하한의 부재

우리가 쓰는 유일한 일반 하한은 강제 발화점 수다. 초기 시도에서 "거리·랭크 기반 하한"(현재 연소 집합에서의 τ-랭크)을 만들었으나, **나중 점화가 더 빨리 활성화시킬 수 있으므로 유효하지 않다**는 반례를 발견해 폐기했다(7.6절). 그 결과 큰 인스턴스에서 우리가 보고하는 값은 상한(휴리스틱)이거나 정확값(작은 n)이며, 중간 규모의 최적성 격차는 알 수 없다. 이는 정직한 한계이며, 동시에 자연스러운 다음 과제다(예: LP 쌍대 기반 하한, 또는 라운드별 최대 확산 용량을 이용한 조합적 하한).

## 7.4 이질성의 범위

이질 임계값 실험은 네 족에 한정된다. 더 중요한 한계는 **임계값 자체가 의사결정 변수**인 상황(예산을 들여 임계값을 낮추는 개입)을 다루지 않는다는 점이다. 단일 섭동 결과(증가 ≤1)는 그런 개입 설계의 첫 단서일 뿐이다.

## 7.5 이론적 깊이

명제 1~10은 증명이 짧다. 가장 내용이 있는 것은 명제 5(압축 보조정리 — 정의에서 잉여 자유도를 제거하고 프로파일을 "추가 확산의 값"으로 재해석), 명제 7(점화 규칙 때문에 자명하지 않은 임계값 단조성), 명제 9(쌍둥이 축약)다. 그러나 임계값 연소의 근사 가능성·경도·상한 개선은 다루지 않았다. 특히 τ≡2에서 나무의 b_2를 다항 시간에 계산할 수 있는지, 또는 NP-난해인지는 이 논문에서 답하지 않는다 — 이것이 이 주제에서 가장 자연스러운 다음 정리이고, 우리는 이를 열린 문제로 남긴다.

## 7.6 실패와 수정의 기록

연구 과정에서 다음 오류를 발견하고 수정했다. (1) **유효하지 않은 하한**: 현재 연소 집합에서의 거리 랭크를 하한으로 쓰고 가지치기했더니 P_24에서 최적 5를 13으로 보고했다. 원인은 "미래의 점화가 활성화를 앞당길 수 있다"는 사실을 무시한 것이었고, 반례를 찾은 뒤 하한을 폐기하고 전수 DP로 교체했다. (2) **계획 재구성 오프바이원**: 점화 간 지연을 상대값으로 저장해 두 점화가 같은 라운드에 놓이는 인증서가 만들어졌다. 인증서 검증기가 이를 잡아냈고, 라운드 절대값으로 바꿨다. (3) **ILP 선형화 부호 오류**: 활성화 지시변수의 두 방향 부등식을 반대로 써서 ILP가 항상 불가능을 반환했다. 세 차례 수정 끝에 DP와 완전히 일치하게 되었다. (4) **검증 그래프 구성 오류**: 바퀴·거미 검증에서 정점 수를 잘못 세어 두 건의 허위 불일치가 났고, 구성을 고친 뒤 0건이 되었다. 이 기록은 "검증을 통과한 수치만 보고한다"는 원칙의 근거다.

## 7.7 주장 수준의 교차 점검

구현 오류(7.6절)와 별도로, 우리는 논문의 주장 자체를 반복해서 되짚었다. 가장 중요한 점검은 **균일 r-연소가 이미 문헌에 있는가**였고, arXiv·출판 검색으로 [Li21]과 [JMT24]를 확인한 뒤 모형 기여의 범위를 이질적 임계값으로 좁혔다(2.2절). 두 번째는 **τ≡1에서 근시안 탐욕이 최적인가**였고, P_6·P_7을 직접 계산해 최적 3 대비 탐욕 4를 얻은 뒤 초록의 "탐욕 0% 열등" 주장을 철회하고 6.7절 수치를 고쳤다. 반면 **메모이즈 DP가 n≤25까지 무난하다**는 초기 추정은 자체 측정(2.2배/정점, n=18에서 8.5초)과 어긋나 받아들이지 않았고, [Bessy16]을 균일 임계값 연소 문헌으로 인용하려던 계획은 원문 확인 결과 연소 상한 논문이어서 무산되었다. 점검 항목 14건의 판정과 조치는 부록 C에 표로 남겼다.

# 8. 결론

정점별 임계값을 갖는 연소 모형에서, 우리는 라운드와 발화점 두 자원을 동시에 기술하는 점화 프로파일 s_k를 정의하고, 이를 정확히 계산하는 DP와 인증서·ILP·브루트포스의 삼중 검증 체계를 만들었다. 구현은 공개된 닫힌 형식 50건을 오차 없이 재현했고, 연결그래프 n≤8 전수와 나무 n≤12 전체, 그리고 1만 2천여 개의 이질 임계값 인스턴스를 계산했다. 그 결과 (i) 임계값이 커지면 연소 수가 평균과 최악 모두에서 급격히 오르고, (ii) 라운드 예산은 τ≡2에서 가장 자주 구속적이며, (iii) τ가 바뀌면 최적 휴리스틱의 정체가 바뀌고(BFF 대 롤아웃 탐욕), (iv) 정점 하나의 임계값 상향은 국소적(≤1라운드)이라는 것을 확인했다.

남은 일은 분명하다. 중간 규모에서 쓸 수 있는 진짜 하한을 만드는 것, 이질 임계값에서 근사 알고리즘과 경도를 다루는 것, 그리고 임계값을 낮추는 개입을 예산 배분 문제로 정식화하는 것이다. 이 논문은 그 문제들의 출발점으로서, 재현 가능한 코드와 원자료, 그리고 인증서를 남긴다.

# 부록 A. 알고리즘 의사코드

**A.1 정확 프로파일 DP**

```
function PROFILE(G, τ, kmax):
  memo ← {}
  function f(mask, r):        # fewest ignitions, plan
    if mask = V: return (0, [])
    if r = 0:    return (∞, ⊥)
    if (mask, r) ∈ memo: return memo[(mask, r)]
    (best, plan) ← f(spread(mask), r−1)        # skip: spread only
    plan ← shift(plan, +1)
    for x ∈ V \ mask (twin representatives only):
      (v, p) ← f(spread(mask) ∪ mask ∪ {x}, r−1)
      if v+1 < best: (best, plan) ← (v+1, [(0,x)] + shift(p, +1))
    memo[(mask, r)] ← (best, plan); return
  for k in 1..kmax: s[k], plan[k] ← f(∅, k)
  return s, plan
```

**A.2 인증서 검증**

```
function VERIFY(G, τ, plan, k):
  rounds ← {}; for (t, x) in plan: if t ≥ k or t ∈ rounds: return False; rounds[t] ← x
  mask ← ∅
  for t in 0..k−1:
    if t ∈ rounds: if x ∈ mask: return False; mask ← step(mask, rounds[t])
    else:          mask ← spread(mask)
    if mask = V: return True
  return mask = V
```
